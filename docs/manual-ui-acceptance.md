# 人工浏览器验收清单

本文件用于在真实浏览器中验收“Chunk 检索 → PDF 证据高亮”和“证据展示问答 → 引用跳转”。

当前自动化测试覆盖 API client、坐标转换、请求竞态、引用 span 转换和后端问答/定位正确性；**本文件中的浏览器步骤不等于已自动执行**。本次开发环境未安装浏览器自动化工具，因此没有声称完成浏览器验收。

## 前置条件

1. 后端已启动：`cd backend && UV_LINK_MODE=copy uv run uvicorn rag_anchor.main:app --port 8000`
2. 前端已启动：`cd frontend && npm run dev`
3. 准备一份可直接选中文字的 PDF，建议满足：
   - 至少 2 页；
   - 同一页有重复文字；
   - 有一条跨行文字；
   - 包含一个可字面检索的关键词（例如 `quick`）。
4. 如有中文 PDF，另准备一份包含中文关键词的样本，用于验证非 ASCII 文本。

## A. Chunk 检索与证据高亮（阶段 A）

- [ ] 上传 PDF 后，文档出现在左侧列表并被自动选中。
- [ ] 点击「建立索引」，状态变为「已索引」，显示页数与 Chunk 数。
- [ ] 输入仅在文档中存在的字面关键词，点击「检索」；结果列表显示页码与字符区间。
- [ ] 点击第一条结果：PDF 跳到对应页，命中位置高亮并滚动到视口中央。
- [ ] 点击第二条结果：新高亮替换旧高亮，不同 occurrence 的矩形位置不同。
- [ ] 跨行证据显示多个行矩形，不是一个覆盖整段的合并大框。
- [ ] 缩放、翻页后再回到命中页，高亮位置随当前 viewport 正确重算。
- [ ] 快速连续点击不同命中：最终显示最后一次点击的命中，旧请求不覆盖新状态。
- [ ] 快速切换文档：旧文档的检索/定位结果不出现在新文档下。
- [ ] 原「证据搜索」面板（M0）仍可检索、跳转、高亮，行为未回归。
- [ ] 关闭后端后执行检索：界面显示错误提示，不显示伪造的成功结果。
- [ ] 人为制造索引与 PDF 不一致（索引后替换后端存储的 PDF 文件），点击结果应显示“这条证据暂时无法可靠定位”，且不生成近似高亮。

## B. 证据展示问答与引用（阶段 B）

- [ ] 选中并索引文档后，「证据问答」按钮可用。
- [ ] 输入自然语言问题，并在「检索关键词」中填写文档原文词句；点击「提问」。
- [ ] 回答区域明确显示“证据展示模式 · 未接入语言模型”，不出现“模型生成”的表述。
- [ ] 引用列表显示 `E1`、页码、字符区间和原文片段；引用全部来自当前文档。
- [ ] 点击引用：使用 `evidence/locate` 返回的矩形跳转并高亮；与 A 中使用同一套高亮路径。
- [ ] 输入不存在的关键词：界面明确显示无法依据文档回答，引用为空，不生成猜测性答案。
- [ ] 问题留空或未建立索引：提问按钮禁用或显示明确提示。
- [ ] 对两个内容相同的文档分别提问：引用始终属于当前选中的文档。
- [ ] 快速连续提交两个问题：最终只显示最后一次问题的回答，旧响应不覆盖新回答。
- [ ] 问答进行中切换文档：旧文档的回答不显示到新文档。
- [ ] 索引后替换后端 PDF 再点击引用：显示 409 对应的“这条证据暂时无法可靠定位”，不重新搜索文字、不画近似矩形，旧高亮不残留为当前引用。
- [ ] 关闭后端后点击提问：显示连接失败错误，不显示伪造的答案或引用。
- [ ] 问答结果区域只以纯文本渲染原文，不执行 PDF 内容中的 HTML 或指令。
